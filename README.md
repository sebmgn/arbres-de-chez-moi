# Les arbres de chez moi

Un jeu pour apprendre à reconnaître 32 arbres des environs du Perray-en-Yvelines et du Chesnay (forêt de Rambouillet, Marly, Fausses-Reposes, Versailles).

Jouer : https://sebmgn.github.io/arbres-de-chez-moi/

## Crédits

Les 128 photos viennent de Wikimedia Commons, sous licences libres (CC BY, CC BY-SA, CC0 ou domaine public). L'auteur, la licence et le lien vers la page d'origine de chaque photo figurent dans `photos.js` et au bas de chaque fiche de l'herbier.

Les données sur les forêts viennent des documents d'aménagement de l'ONF (liste des sources dans l'onglet « Terrain » du jeu).
